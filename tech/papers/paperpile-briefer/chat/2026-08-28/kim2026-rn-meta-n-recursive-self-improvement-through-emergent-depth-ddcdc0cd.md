# Paperpile Brief 2026-08-28 - Meta^n: Recursive self-improvement through emergent depth

## 基本情報

- **タイトル**: Meta^n: Recursive self-improvement through emergent depth
- **著者**: Zae Myung Kim, Young-Jun Lee, Seungyeon Jwa, Dongyeop Kang
- **年 / venue**: 2026 / arXiv [cs.AI]（Preprint）
- **リンク**: [arXiv:2608.24735v1](https://arxiv.org/abs/2608.24735v1) / [Code](https://github.com/minnesotanlp/meta-n)

## 落合陽一フォーマット

- **ひとことでいうと**: LLMエージェントの改善器そのものは固定したまま、その入出力を再帰的に積み上げて「改善のための改善」を深くする、自己改善エージェント Meta^n を提案した論文。
- **先行研究と比べてどこがすごい？**: Self-Refineや進化的探索、自己改変エージェントは、改善機構の一部を固定して安定性を確保するため、実質的なメタ改善の深さが浅いと著者らは捉える。Meta^n は固定メタ操作 Ω を各層で再利用し、下位層の実行トレースと生成コードを入力として増やす設計で、安定性を損なわず深さを得る。8種類のベンチマーク群・2バックボーンで既存自己改善手法を上回ったと報告し、ARC-AGI-2 でも唯一ゼロ超えを達成したとしている。
- **技術や手法の肝はどこ？**: 各層は固定の Ω により、(1) タスク前に戦略的文脈を与える Python の pre-process と、(2) 下位ソルバが呼べる再利用可能な関数ライブラリを生成する。次層は前層までのコードと全タスクの失敗・成功トレースを見て、方針の追加・修正・ロールバックを行う。深さは事前固定せず、改善が止まるまで成長させ、複数の層チェーンは進化的アーカイブで保持する。
- **どうやって有効だと検証した？**: 組合せ最適化、分類、端末操作、数理発見、記号回帰、アルゴリズム高速化、ARC-AGI-2 など8ベンチマーク群で比較した。CO-Benchでは再帰を除くと検証スコアが 0.845 から 0.714 に低下し、層間コンテキストを除く低下も大きい。再帰による利得の大半は、層間で受け渡す戦略的コンテキストに由来すると分析している。
- **議論はある？**: メタ層の深さや「既存法は約2.5層まで」という整理は著者らの定義に依存する。また、同一モデルをベースソルバと Ω の双方に使う実験設計であり、強いモデルを改善器にだけ使う実運用条件は未検証。深い層ほど平均性能が常に上がるわけではなく、層間干渉による回帰をアーカイブ選択で補う必要がある。
- **次に読む/試すなら**:
  - CO-Bench相当の複数タスク環境で、共有ライブラリと層間コンテキストの寄与を個別に再現する。
  - Ω が生成する自由形式コンテキストを構造化・型付き表現に置き換え、安定性を比較する。
  - 強いモデルを Ω、安価なモデルをベースソルバに置く非対称構成を評価する。
